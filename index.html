9 journées structurées en chapitres progressifs pour une formation complète aux Web Services

Jour 1 Fondamentaux

Introduction aux Web Services

Concepts clés, architecture client-serveur, formats d'échange

  • HTTP/HTTPS et méthodes
  • JSON vs XML
  • Codes de statut HTTP
Jour 2 REST

Introduction aux API REST

Principes REST, design d'API, conception de réponses

  • 6 contraintes architecturales REST
  • Conventions de nommage
  • Structure des URLs

Jour 3 Avancé

Développement d'API REST Avancé

Jour 4 Sécurité

  • Monitoring et observabilité
